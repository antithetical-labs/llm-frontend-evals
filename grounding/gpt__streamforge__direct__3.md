The visual direction should interpret **acid design as controlled digital intensity**, not as a pile of neon effects. Streamforge is a professional developer platform, so the interface can feel experimental, fast, and slightly confrontational while preserving the clarity expected from an IDE.

**Palette.** Start with a near-black base—closer to blue-black or charcoal than pure black—to evoke terminals, late-night coding, and live production environments. Use one dominant “toxic” accent such as electric chartreuse, with ultraviolet, hot magenta, and sharp cyan as secondary signal colors. These colors should behave functionally: green for live states and successful builds, violet or cyan for AI activity, magenta for forks or audience interaction. Off-white text will be easier on the eye than stark white. Large areas remain dark and restrained so the acid colors feel luminous rather than decorative.

**Typography.** The primary type should be a modern grotesk or neo-grotesk with tight spacing and a slightly industrial character. Headlines can be oversized, compressed, or unusually wrapped to create the feeling of a rave poster translated into a product interface. A highly legible monospaced face should carry prompts, model output, repository details, timestamps, viewer counts, and technical labels. The contrast between assertive display typography and disciplined monospace makes the product feel both cultural and credible. Type treatments may include outlined words, terminal cursors, bracketed labels, and occasional italic or skewed emphasis, but body copy should remain conventional and readable.

**Texture.** Acid design gains energy from synthetic imperfection: fine monochrome noise, scan lines, dithered gradients, halftone fields, low-resolution icons, chromatic offsets, and subtle signal distortion. These should appear as atmospheric layers or interaction feedback—not over the core reading surfaces. Code, prompts, and model responses need clean, high-contrast panels. Chrome, iridescent gradients, and translucent “screen” materials can be used sparingly for major brand moments, while thin grid lines and coordinate marks suggest a live technical system.

**Layout logic.** The composition should feel like a broadcast console crossed with an editorial poster. Use a strong underlying grid, then deliberately let selected elements break it: an oversized headline crossing columns, a live badge pinned to an edge, a code window overlapping the hero, or metadata running vertically. Dense technical information can sit beside large areas of negative space. Panels should resemble modular IDE panes rather than generic rounded SaaS cards. Borders can be thin and bright, corners mostly square or only slightly rounded, and section changes can feel like switching channels or entering a new workspace.

The page should foreground the product’s unique viewing model. Prompt, AI response, code diff, terminal output, and repository state should appear as synchronized layers of one live event—not as unrelated feature cards. Motion, when implemented, should communicate progression: a prompt being submitted, tokens arriving, code changing, tests running, and a repository becoming forkable. Glitches should mark transitions or live activity, never interrupt reading.

This direction borrows from **1990s acid-house and techno flyers, cyberdelic graphics, early web interfaces, demoscene visuals, CRT terminals, hacker culture, industrial labeling, and contemporary creative-coding tools**. It also borrows the visual confidence of underground music culture: oversized type, abrasive contrast, compressed information, and deliberately synthetic color.

It rejects the polished neutrality of conventional B2B SaaS—soft blue gradients, friendly blobs, generic illustrations, endless floating cards, and excessive pill shapes. It also rejects nostalgia for its own sake. Streamforge should not look like a parody of Windows 95, a fake terminal, or a chaotic Y2K collage. The result should feel current and operational: an advanced live workspace with the voltage of an underground broadcast.

The overall mood is **live, technical, participatory, and slightly dangerous**. It should suggest that something is being invented in public right now—and that the viewer can inspect it, learn from it, and fork it before the stream is over.
