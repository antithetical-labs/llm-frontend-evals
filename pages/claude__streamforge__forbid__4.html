How it works

Three moving parts, one synchronized timeline.

Streamforge captures the assistant session and the git working tree together, so nothing about a build is a black box.

01

A developer goes live

Run forge go in your project directory. The CLI attaches to your AI assistant session and your local repo — no screen capture, no OBS scene to configure.

02

Viewers read along

Prompts, model output, tool calls, and file diffs stream as structured events. Scrub backwards to any moment; the code pane rewinds with you.

03

Anyone forks the result

Every stream is a real repository. Fork at the live head or at any earlier commit, and the full prompt history comes along as annotated notes.
