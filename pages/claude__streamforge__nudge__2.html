01How it works3 steps

Point it at your repo. Everything else is automatic.

Streamforge hooks into your editor and your assistant, not a webcam and a mixer. You keep working; the timeline records itself.

01

Attach the agent

Install the CLI, run forge live in your project. It captures your prompt stream, the model's response, and the resulting git diff as three synced tracks.

02

Build in the open

Viewers see the prompt panel, the model output, and the file tree side by side. Chat threads pin to a specific prompt, so feedback lands where it's relevant.

03

Anyone forks the moment

Every commit is a public checkpoint. Scrub to minute 42, hit fork, and get the repo exactly as it stood — plus the prompt history that produced it.
