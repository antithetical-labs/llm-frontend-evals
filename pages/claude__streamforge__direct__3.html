HOW IT
RUNS

Four stages. No plugins to configure, no OBS scene graph to hand-build. Point the CLI at a repo and it wires the rest.

01

Attach the agent

Run sf watch . next to your assistant. Streamforge taps the prompt/response channel and the file watcher — no screen capture, no video encoder in the loop.

/ 4 SECONDS
02

Go live

Three synced tracks: prompt transcript, model output with token timing, and a live diff of the working tree. Viewers pick their own layout.

/ SUB-400MS LAG
03

Audience intervenes

Chat can suggest prompts, flag a hallucinated API, or vote on which of two approaches you take next. You keep the commit bit.

/ OPTIONAL
04

Anyone forks

Every commit is a public checkpoint. One click clones the repo at that hash with the full transcript attached as build context.

/ FOREVER

THREE THINGS
THE PLATFORM DOES

Built for people who already read diffs for a living. Everything below is on by default.

/ 01 — TRANSPARENT CONTEXT

The whole prompt, not the highlight reel

Most AI content shows you a finished result. Streamforge shows the seventeen prompts that got there, including the four that failed and the one where the model confidently invented a library.

  • Full transcript, timestamped to the diff
  • Token cost + latency per turn
  • System prompt visible or sealed, your call
  • Searchable across every archived stream
/ 02 — REALTIME CODE SURFACE

Diffs that land while you watch

The code pane is a real editor view driven by filesystem events, not a video of one. Scroll it, expand a hunk, jump to definition, copy a line — all mid-stream, without pausing the broadcast.

  • Text-native, so it stays crisp at any size
  • Tests and terminal output as separate tracks
  • Rewind to any commit on the timeline
  • Syntax support for 240 languages
/ 03 — FORK ANYTHING

Every stream is a repo you can take

Watching is the shallow version. Fork mid-session and you get the tree at that hash, the transcript as context, and the agent config already set — so you can continue in a direction the streamer didn't.

  • One-click fork at any commit
  • Transcript imports as agent memory
  • Fork graph shows every branch taken
  • Licence and attribution carried across
