How it works

From blank repo to shipped feature, in public

Streamforge captures the whole loop — intent, prompt, model output, diff — so nothing about the process is lost.

01

Go live with your assistant

Connect your editor and your AI tool of choice. Streamforge broadcasts your prompts, completions, and code changes as one synchronized feed.

02

Viewers follow the reasoning

The audience sees not just the code, but the conversation that produced it — including the prompts that failed and the ones that worked.

03

Fork and keep building

Every stream is backed by a real repository. Fork it at any commit, replay the full prompt history, and continue where the streamer left off.

Features

Built for people who ship code for a living

No highlight reels. No polished demos. Just the real workflow, captured and made useful.

Prompt-aware streaming

Prompts, model responses, and diffs render side by side in real time. Scrub the timeline to see exactly which prompt produced which change, down to the commit hash.

One-click repo forking

Every stream ships with a living repository. Run forge fork kira/auth-service or click once in the UI — prompt history and context come along with the code.

Chat that speaks code

Ask the streamer why they rejected a completion, suggest a better prompt, or reference a specific diff inline. Discussions attach to commits, not just timestamps.
