THE LOOP

From prompt to pull request, in the open

Every stream is a working session, not a lecture. Three things happen, over and over.

01 / PROMPT

The ask is on screen

Viewers read the exact prompt the streamer sends, including the false starts and rewordings. The craft of asking is the content.

02 / GENERATE

The model answers live

Output streams in token by token next to the editor. Accepted, edited, or rejected — you see the judgment call, not just the result.

03 / COMMIT

The repo is the replay

Every accepted change lands as a real commit. Missed the stream? Scrub the history, or run forge fork and build on top of it.

BUILT FOR WORKING DEVS

Everything downstream of the stream

The broadcast is the beginning. These are the tools that make it useful after you close the tab.

⎇

One-click repo forking

Every stream carries its repository. Fork the exact state from any timestamp and pick up where the streamer left off, dependencies included.

GIT-NATIVE
⌘

Searchable prompt transcript

Prompts and model responses are indexed alongside the diff they produced. Search "retry backoff" and jump to the moment it was solved.
