§ 01How it worksThree moves

Three panes.
One session.
Zero post-production.

A Streamforge broadcast is not a screen recording. It's a structured feed: the prompt channel, the model's token stream, and the git state, all timestamped against the same clock. Scrub backwards and the code goes with you.

A / Prompt channel

Every prompt, on the record

  • Model, temperature & context size on the HUD
  • Rejected completions kept, not hidden
  • Deep-link any prompt at any timestamp
