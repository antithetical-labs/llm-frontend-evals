// how it works

Three steps. Zero production value required.

01

Connect your session

Install the CLI and point it at your repo. Run forge live and your terminal, editor, and AI assistant session are multiplexed into one stream.

02

Build like you always do

Prompt, review, edit, commit. Viewers watch the conversation with the model and the code evolving side by side — nothing staged, nothing edited.

03

Viewers fork the repo

Every stream is backed by a live repository. Anyone watching can fork the exact state at any timestamp and keep building from where you left off.
