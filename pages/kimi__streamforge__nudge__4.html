// 01 — HOW IT WORKS

Three steps. Zero polish. All signal.

01

Go live from your editor

One command — npx streamforge go-live — and your session is broadcast: keystrokes, prompts, model responses, and the git history as it happens.

02

Build in public, with your AI pair

Viewers see the prompt and the output side by side. They watch you accept, reject, and steer the model — the part no blog post ever shows.

03

Anyone can fork the repo

Every stream is backed by a live repository. One click and a viewer's fork is cloned at the exact commit they're watching — prompts included as metadata.

// 02 — FEATURES

Built for people who read diffs for fun.

Prompt-over-code view

A split timeline: the prompt on the left, the generated diff on the right. Scrub back to any exchange and see exactly what instruction produced what code.

avg. prompt visibility: 100% — nothing edited post-hoc

One-click forking

Fork any stream at any moment. Your copy pins the commit, the dependency lockfile, and the full prompt transcript — so it runs, and you know why it runs.

median time from fork → local run: 41 seconds

Signal, not spectacle

No face cams required, no overlay graphics. Chat is threaded to specific lines of code. CI status, test runs, and model latency stream alongside the video.

chat threads anchored to: file:line, not vibes
