How It Works

[ protocol_v2 ]
01

Go live from your editor

Install the Streamforge plugin for VS Code, Neovim, or JetBrains. One command — forge stream — and your session is broadcasting: keystrokes, terminal, and AI assistant traffic included.

02

Build in public, with the machine

Viewers see your prompts, the model's raw output, and the code evolving in real time. Chat can suggest prompts, vote on approaches, or just lurk and learn how you actually work.

03

Anyone can fork the stream

Every stream is backed by a live git repo. One click snapshots the code at this exact moment — prompts and model context included — straight into the viewer's account.
