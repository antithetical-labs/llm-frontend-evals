How it works

From prompt to pull request, in public.

No highlight reels. Every stream shows the full loop — including the dead ends and the prompts that flopped.

1

Go live with your editor

Connect your repo and your AI assistant of choice. Your prompts, model responses, and diffs stream side by side — no extra tooling to learn.

2

Build with an audience

Viewers follow along in real time, flag issues in chat, and see exactly which suggestions you accept, edit, or reject — and why.

3

Ship a forkable repo

Every stream is backed by a live repository. Anyone watching can fork it mid-stream and pick up right where you are.

Features

Built for developers who actually ship.

Streamforge isn't video with a chat bolted on. The stream, the prompts, and the code are one thing.

Prompt-transparent streams

Every prompt and every model response is rendered next to the code it produced. See the reasoning, not just the result — and learn what actually works with each model.

FULL CONTEXT, ALWAYS

One-click repo forking

Spotted a better approach? Fork the stream's repository at any commit — even mid-broadcast — and open a pull request the streamer can review live on air.

Code-aware chat

Chat messages can reference files, lines, and diffs directly. Comments anchor to the code, so feedback survives the scroll and lands where it matters.
