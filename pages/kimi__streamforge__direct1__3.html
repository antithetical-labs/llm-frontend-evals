The protocol

How it works

01

Go live with your stack

Connect your editor, your terminal, and your AI assistant. Streamforge captures the full loop — every prompt you write, every token the model returns, every diff that lands.

02

Build in the open

Viewers watch the real process: dead ends, hallucinations, hot fixes, and the moment it compiles. Chat can suggest prompts, vote on approaches, or flag a bug before you see it.

03

Fork the repo, keep building

Every stream is backed by a live repository. Any viewer can fork it at any timestamp and continue from the exact state of the code — prompts and history included.

Under the hood

Built for builders

⟁

Prompt Trace Overlay

A synchronized side-channel renders every prompt and model response alongside the code. Scrub the timeline and see exactly which instruction produced which diff — the AI workflow, fully legible.

CORE
⑂

One-Click Stream Forks

Every broadcast is a versioned repo. Fork from any commit or any minute of the stream, clone the prompt history with it, and keep building where the streamer left off — attribution baked in.

◉

Multi-Model Lenses

Streaming with Claude, GPT, or a local Llama? Tag your assistant and viewers filter streams by model, language, or task. Compare how different models solve the same problem, live.
