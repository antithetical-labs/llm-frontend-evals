Features

Live Prompt Telemetry

sys.monitor_input()

Don't just watch the code appear. Our editor plugins capture every prompt, context inclusion, and system instruction the broadcaster uses, displaying it in an isolated, readable stream.

Time-Travel Diff

git.watch_head()

Rewind any stream to see exactly what changed. The viewer UI separates human keystrokes from AI-generated blocks, letting you analyze the ratio and integration strategy.

Instant State Fork

repo.clone_at_timestamp()

Every stream is tied to a live Git session. Click 'Fork' at any point in the broadcast to grab a zip of the repo precisely as it exists on the broadcaster's machine in that moment.
