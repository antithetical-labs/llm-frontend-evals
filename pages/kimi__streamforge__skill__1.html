How it works

Your editor is the stage. Three steps and you're on air.

$ forge init

Connect your repo

Point the CLI at any local repository. Streamforge watches your working tree, your terminal, and your assistant session. No OBS, no scene setup.

$ forge live

Build in public

Stream your prompts, the model's responses, and every diff as it lands. Viewers see the full reasoning loop, not a highlight reel.

$ git fork

Let viewers fork

Every stream carries its repo state. Anyone watching can fork your code at the current commit and keep building where you left off.

Features

Built for how developers actually watch and work.

⌘

Prompt-level replay

Scrub a stream by prompt, not by timestamp. Jump to the exact exchange where the schema changed or the bug appeared, with the code state at that moment.

⎇

One-click repo forks

Fork any stream's repository at any commit in the session. The fork includes the full prompt history as PROMPTS.md, so the context travels with the code.

◫

Multi-pane layout

Editor, terminal, assistant chat, and diff view in one composable grid. Viewers rearrange panes on their side without touching your setup.

Early access

Ship your next project with an audience.

We're onboarding streamers in weekly cohorts. Drop your email and we'll send an invite with the CLI install command.
