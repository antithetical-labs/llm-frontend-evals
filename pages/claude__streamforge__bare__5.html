// lazy refill
take(n = 1) {
  const now = performance.now();
  this.tokens = min(
    this.cap,
    this.tokens +
      (now - this.last) * this.rate
  );
  this.last = now;
  return this.tokens >= n;
}

How it works

Three moving parts, one timeline.

Streamforge records the conversation, the repository, and the terminal as a single synchronized stream — so nothing happens off-screen.

Connect your editor

Install the CLI or the VS Code extension, run forge go, and your session is broadcasting in under ten seconds. Secrets and .env files are redacted by default.

→

Build out loud

Every prompt, tool call, model response, diff and test run lands on a shared timeline. Viewers scrub back, drop timestamped comments, and suggest prompts you can accept with one keystroke.

→

Anyone forks it

Hit Fork at any point and you get the repo at that exact commit plus the full prompt history as context. Pick up where the streamer was, in your own sandbox.

→

Built for people who ship

Not a screen recording. An executable artifact.

Streamforge treats a stream as a first-class repo with a replayable history — searchable, diffable, and forkable long after the streamer goes offline.

⑂

Fork any moment

Scrub to minute 42, fork, and get a private repo seeded with that commit and the preceding prompt transcript. Your AI assistant loads the same context the streamer had — including the dead ends.
