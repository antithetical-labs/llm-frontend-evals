How it works

01 / BROADCAST

Connect your editor

Install the Streamforge extension. It securely streams your active editor pane, your AI assistant panel, and your terminal stdout. No desktop capture required.

02 / EXPOSE

Reveal the workflow

Viewers see exactly what you type into Copilot, Claude, or ChatGPT. They see the diffs generated, and whether you accept, modify, or reject them.

03 / COLLABORATE

Live-forking

Every stream is attached to a temporary Git repository. Viewers can hit 'Fork' at any moment to branch off the streamer's exact local state and experiment.

Platform capabilities

Prompt visibility

Stop guessing how senior engineers use LLMs. The prompt stream is treated as a first-class citizen alongside the video and code.

Time-travel diffs

Scrub back through the VOD not just by video timestamp, but by code state. See the exact state of the project before and after a specific prompt execution.

Zero-setup environment

Click any active stream to spin up a web-based IDE populated with the streamer's exact current file tree. Test their generated code immediately.
