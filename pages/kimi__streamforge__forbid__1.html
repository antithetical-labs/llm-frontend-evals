How it works

From first prompt to forkable repo in three steps.

1

Connect your stack

Link your editor, terminal, and AI assistant with one CLI command. Streamforge captures prompts, completions, and file diffs automatically — no screen sharing hacks.

2

Build in public

Go live and build something real. Viewers see your prompt history, the model's raw output, and the code evolving side by side, synced to your git commits.

3

Let viewers fork

Every stream is backed by a live repository. Anyone watching can fork the code at any commit, continue in their own sandbox, or open a pull request mid-stream.

Features

Built for developers who ship with AI.

Prompt-transparent streams

The full conversation with your AI assistant is part of the broadcast — nothing hidden, nothing edited after the fact.

  • Prompts and responses render in real time
  • Model, temperature, and token counts shown
  • Replay any stream with the full timeline

One-click repo forking

Every stream is a living git repository. Fork it at any commit and keep building from exactly what you saw on screen.

  • Fork at any point in stream history
  • CI runs automatically on every fork
  • Open PRs back to the streamer live

Chat that reads code

Viewer chat is diff-aware. Reference a line, suggest a prompt, or vote on which approach the streamer should try next.

  • Inline comments on live diffs
  • Suggest-a-prompt queue with voting
  • Code snippets render with syntax highlighting
