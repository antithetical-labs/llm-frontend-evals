// The Protocol

How it works

01

Broadcast the build

Go live with your editor, terminal, and AI assistant in one unified stream. Every keystroke, every prompt, every completion — transmitted raw with <50ms latency.

02

Audience rides along

Viewers watch the model's output stream in token by token, see diffs apply live, and drop prompts into chat that you can accept straight into your session.

03

Fork the artifact

Every stream is backed by a real repository. One click forks the exact state of the code — commits, history, and prompt log included — directly to the viewer's account.

// Core Systems

Built for the AI-native workflow

Prompt-Visible Streaming

The prompt log is a first-class citizen of the broadcast. Viewers see exactly what you asked, what the model returned, and what you kept — the full decision trail, not just the final code.

Transparency Engine

One-Click Repo Forking

Any stream's repository can be forked at any timestamp. Grab the code as it existed at minute 12, rewind to before the refactor, or take the final build — prompt history included.

Time-Travel Git

Collaborative Prompting

Viewers submit prompt suggestions in chat; the best ones rise by upvote and can be injected into your session with a single keystroke. The crowd becomes your co-pilot's co-pilot.
