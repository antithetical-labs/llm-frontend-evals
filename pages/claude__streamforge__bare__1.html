// bounded retry w/ jitter
export async function withRetry<T>(
  fn: () => Promise<T>,
  max = 5
) {
  for (let i = 0; i < max; i++) {
    try { return await fn(); }
    catch (e) { await sleep(jitter(i)); }
  }
  throw new DropError("exhausted");
}

How it works

Three commands between you and an audience.

Streamforge hooks into your editor and your git history — not your webcam. Your terminal is the show.

Connect your agent

Install the CLI and point it at your project. Streamforge captures prompts, model output, and file diffs straight from your session — with a redaction filter for secrets and env files.

Go live and build

Viewers get a synced three-pane view: your prompts, the assistant's reasoning, and the code tree updating as commits land. Chat can suggest prompts you can accept with one keystroke.

Ship the repo

Every stream ends with a real, cloneable repository and a timeline you can scrub. Viewers fork from any commit and continue the build in their own branch.
