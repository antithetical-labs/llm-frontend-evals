F—01 / TIMELINE

The diff is the video

Streamforge doesn't record pixels. It records events — prompt submitted, token emitted, file patched, test run, commit made — and reconstructs the session in the player. That means the timeline is seekable at the granularity of a single change, the code is selectable text, and a four-hour build is a few megabytes instead of a few gigabytes.

  • Scrub to any prompt, not any second
  • Copy code straight out of the player
  • Full-text search across every stream ever aired
  • Test runs and failures pinned to the timeline

F—02 / FORK

Fork any stream, any moment

Every broadcast is a live git remote. Hit fork and you get the tree exactly as it stood at the commit you were watching, plus the complete prompt transcript attached as commit notes — so you inherit not just the code but the reasoning that produced it. Streams routinely branch into a dozen forks mid-session, and the player shows you the whole tree.

  • One-click fork from live or archive
  • Prompt transcript travels as git notes
  • Diverge from a stream and stream your own fork back
